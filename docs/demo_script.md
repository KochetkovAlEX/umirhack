# Сценарий видео-демо (≤ 3 минуты)

Подготовка: `tasks.ps1 serve` (бэкенд + собранный фронтенд на :8000), `python -m bot` с BOT_TOKEN, открыт http://localhost:8000 и Telegram.
Файлы: `data/documents/open-002.png` (справка без даты выдачи), `open-018.png` (полное заявление), `open-030.pdf` (практика без подписи и печати),
фото телефоном любой справки под углом (или `bench_out/photo_combo/open-001.png`).

| Время | Действие | Что сказать |
|---|---|---|
| 0:00–0:15 | Слайд/заставка | Деканат вручную переписывает документы; наш сервис читает фото, собирает карточку и отвечает по Положению. |
| 0:15–1:00 | Веб: загрузить `open-002.png`, тип «автоматически», вопрос «Хватит ли справки для перевода на 2 курс?» | Тип определён сам; поля на снимке подсвечены; не хватает даты выдачи — п. 3.1; условия перевода Положение не устанавливает (п. 3.5); решение примет сотрудник деканата. Клик по `rule:3.1` — текст пункта. |
| 1:00–1:25 | Веб: `open-018.png`, кнопка «Проверить без вопроса» | Заявление содержит все обязательные сведения по п. 4.1, 4.2. Вкладка «Распознанный текст». Вопрос «Есть ли печать?» → для заявления печать не требуется (п. 4.3). |
| 1:25–2:00 | Telegram: отправить `open-030.pdf`, выбрать «Справка о практике», спросить «Кто руководитель практики?» | Карточка полей, предпроверка: нет подписи и печати (п. 5.2, 5.3). На вопрос — значение поля и фрагмент снимка с рамкой. |
| 2:00–2:20 | Telegram или веб: «Какой размер стипендии положен студенту?» | Честный отказ по п. 6.3: в документе и Положении нет информации, обратитесь в деканат. |
| 2:20–2:45 | Веб: фото под углом / с тенью; показать YAML нового типа в `config/doc_types` и его появление в списке типов | Предобработка выравнивает снимок; новый тип документа добавляется конфигом без кода. |
| 2:45–3:00 | Терминал: `python scripts/predict.py ... --reference` → метрики 1.0 | Автопроверка организаторов: все три метрики 1.0 на открытом наборе; стек локальный, без внешних API. |
